# Moje Portfolio

Jest to moje osobiste portfolio, które stworzyłem, żeby zaprezentować siebie, swoje umiejętności oraz projekty, nad którymi pracowałem.

## O mnie

Cześć! Nazywam się Wiktor i uczę się w technikum na kierunku technik informatyk.

Interesuję się programowaniem, szczególnie tworzeniem stron internetowych. W wolnym czasie rozwijam swoje umiejętności, uczę się nowych technologii i tworzę własne projekty.

## Wykorzystane technologie

- HTML
- CSS
- JavaScript

## Co znajduje się na stronie?

- **Strona główna** – krótkie przedstawienie mojej osoby.
- **O mnie** – kilka informacji o mnie i moich zainteresowaniach.
- **Umiejętności** – technologie i narzędzia, z których korzystam.
- **Projekty** – wybrane projekty, które stworzyłem.
- **Kontakt** – informacje, dzięki którym można się ze mną skontaktować.

## Dodatkowe funkcje

- Dostosowanie strony do różnych rozmiarów ekranów.
- Animacje i płynne przewijanie strony.
- Menu na urządzenia mobilne.
- Animowany tekst na stronie głównej.
- Przycisk powrotu na górę strony.
- Formularz kontaktowy.

## Jak uruchomić projekt?

1. Pobierz repozytorium na swój komputer.
2. Otwórz folder z projektem w Visual Studio Code.
3. Uruchom plik `index.html` w przeglądarce.

Możesz również skorzystać z rozszerzenia Live Server w Visual Studio Code.
